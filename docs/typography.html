Главное правило: сначала кириллица, потом красота

Проверено запросами к fonts.googleapis.com

Большинство эффектных шрифтов из референсов — латиница-онли. Если такой шрифт подключить, браузер не покажет ошибку: он молча подставит системный запасной, и заголовок станет безликим. Именно это случилось с Michroma в блоке «Три формата работы» — шрифт грузился корректно, но его кириллица нарисована автогенерацией и не имеет ничего общего с фирменной широкой латиницей.

01

Восемь комбинаций

Каждая — три роли: дисплей / текст / метки

Формула во всех парах одна: дисплейный шрифт для заголовков, нейтральный для текста, моно или разряженный капс для меток и цифр. Третий шрифт нужен именно для мелочи — это то, что отличает референсы от обычных лендингов. Образцы ниже — на реальном тексте сайта.

02

Шестнадцать приёмов

Работают на любой паре из раздела 01

Разница между «нормальным лендингом» и референсами — не в шрифте, а в этих мелочах. Их можно набирать по 3–4 штуки на страницу: больше — превращается в кашу. Слева живой пример, справа код для копирования.

01

Курсив на смысловом слове

Базовый приём всех референсов («HI, I'm TIARA», «IDENTITY IN MOTION»). Выделяем курсивом одно слово — то, которое несёт смысл, а не служебное. Держит внимание и добавляет «руки дизайнера» без единого дополнительного шрифта.

От текущих продаж к управляемой прибыли

<h2>От текущих продаж <em>к управляемой</em> прибыли</h2>

h2 { font-family: 'Playfair Display', serif; font-weight: 600; }
h2 em {
  font-style: italic;
  font-weight: 400;      /* курсив всегда легче основного */
  color: var(--ink-soft);
}
02

Три кегля в одном заголовке

Заголовок собирается из строк разного размера: мелкая метка, огромное главное, среднее курсивное. Создаёт ритм и «постерность» — как в Tiara и Alora. Работает, только если размеры отличаются заметно (в 2–3 раза), иначе выглядит случайностью.

03

Гигант, обрезанный краем экрана

Слово набирается настолько крупно, что физически не помещается, и уходит за край («SERRINA.C», «MY VALUES MY V»). Мгновенно читается как дизайн-решение, а не как ошибка вёрстки. Обязательное условие — слово должно угадываться по первым буквам.

05

Микро-метки капсом с разрядкой

Самый дешёвый способ поднять уровень вёрстки: над каждым блоком — крохотная строчка капсом с разрядкой 0.3em. Есть буквально во всех 19 референсах. Правило: чем мельче кегль, тем больше разрядка.

01 — Ассортимент

Что продавать, в каком объёме и по какой цене, чтобы юнит-экономика сходилась.

.label {
  display: block;
  font-size: 10.5px;          /* 10–12px, не больше */
  font-weight: 500;
  text-transform: uppercase;
  letter-spacing: .34em;      /* 0.25–0.4em */
  color: var(--muted);
  margin-bottom: .9rem;
}
/* разрядка добавляет пробел справа от последней буквы —
   компенсируем, если метка выравнивается по правому краю: */
.label.right { margin-right: -.34em; }

Оптика крупного кегля

Главная техническая причина, почему свои заголовки выглядят «дешевле» референсных. Крупный текст нужно сжимать (минусовой трекинг, интерлиньяж меньше единицы), мелкий — разряжать. Плюс text-wrap: balance, чтобы последняя строка не оставалась одиноким словом.

.h-lg  { font-size:clamp(1.8rem,4vw,3rem);   letter-spacing:-.025em; line-height:1.06; }

}

04

Гигиена

Что проверять перед тем, как считать готовым

Максимум три шрифта

Дисплей + текст + моно. Четвёртый почти всегда означает, что один из трёх выбран неправильно.

Только нужные веса

Каждый вес — отдельный файл. Сейчас в index.html грузится Inter:300..900 — девять начертаний. Реально используются 3–4.

Чистить неиспользуемое

Archivo и Rubik Mono One подключены, но не используются в CSS. У Archivo к тому же нет кириллицы — удалить из <link>.

Трекинг по кеглю

Крупное сжимаем (-.02…-.04em), мелкий капс разряжаем (.25….4em). Средний текст оставляем в покое.

Интерлиньяж по кеглю

Заголовки .94–1.08, текст 1.55–1.65, моно 1.7+. Один line-height на всё — типичная ошибка.

Длина строки

Заголовок до 20ch, абзац 60–70ch. Иначе глаз теряет начало следующей строки.

preconnect обязателен

Нужны оба: fonts.googleapis.com и fonts.gstatic.com с crossorigin. Второго в проекте сейчас нет.

Проверка на длинных словах

«Ассортимент», «Консультация», «Маркетплейсы» — на них ломается широкий дисплейный шрифт. Проверять до финала, а не после.

Русская типографика

Тире «—» вместо дефиса, «ёлочки» вместо кавычек, неразрывный пробел перед ₽, % и после коротких предлогов.
