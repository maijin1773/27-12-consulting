Библиотека анимаций

Живые примеры, а не просто термины: каждый эффект можно посмотреть в деле и сразу скопировать код. Организовано по тем же категориям, что и глоссарий (animation-vocabulary) — появление, тайминг, трансформации, переходы, скролл, обратная связь, easing.

01

Появление и исчезновение

Fade · Slide · Scale · Pop · Reveal

Пять базовых способов ввести элемент в кадр. Разница — не в идее (все идут от «невидимо» к «видимо»), а в кривой и добавленном свойстве. Pop добавляет перелёт (overshoot) через cubic-bezier(.34,1.56,.64,1), Reveal вместо прозрачности использует clip-path.

/* Pop: та же идея, но с "перелётом" через cubic-bezier */
.pop    { opacity:0; transform:scale(.4);
           transition:transform .55s cubic-bezier(.34,1.56,.64,1),
                       opacity .3s ease; }
.pop.in { opacity:1; transform:scale(1); }

/* Reveal: прячем через clip-path, а не opacity */
.reveal    { clip-path:inset(0 100% 0 0);
              transition:clip-path .7s cubic-bezier(.65,0,.35,1); }
.reveal.in { clip-path:inset(0 0% 0 0); }

02

Тайминг и последовательность

Stagger · Orchestration

Группа элементов входит не разом, а с небольшой задержкой друг за другом — создаёт ощущение «каскада». Технически — та же entrance-анимация, но у каждого следующего элемента transition-delay на 60–80ms больше.

.item {
  opacity:0; transform:translateY(16px);
  transition:opacity .45s ease, transform .45s ease;
}
.row.in .item { opacity:1; transform:translateY(0); }

/* Задержка растёт для каждого следующего элемента */
.row.in .item:nth-child(1) { transition-delay: 0ms;   }
.row.in .item:nth-child(2) { transition-delay: 70ms;  }
.row.in .item:nth-child(3) { transition-delay: 140ms; }
.row.in .item:nth-child(4) { transition-delay: 210ms; }

// Или программно, на любое число элементов:
items.forEach((el, i) => {
  el.style.transitionDelay = `${i * 70}ms`;
});

Движение и трансформации

Наведите курсор на фигуры

Четыре базовых 2D-трансформации плюс их 3D-версия. 3D tilt — тот же приём, что уже стоит на карточках нашего сайта: угол поворота считается от положения курсора внутри карточки. Perspective — не трансформация, а свойство контейнера: чем меньше значение, тем сильнее эффект глубины при том же повороте.

3D tilt (mouse-follow) — как на карточках сайта
двигайте курсором
.tilt { transition: transform .12s ease-out; will-change: transform; }

el.addEventListener('mousemove', (e) => {
  const r = el.getBoundingClientRect();
  const px = (e.clientX - r.left) / r.width;   // 0..1
  const py = (e.clientY - r.top) / r.height;  // 0..1
  const rotateY = (px - 0.5) * 20;
  const rotateX = (0.5 - py) * 20;
  el.style.transform =
    `perspective(700px) rotateX(${rotateX}deg) rotateY(${rotateY}deg)`;
});
el.addEventListener('mouseleave', () => { el.style.transform = ''; });

Accordion — высота через grid-template-rows

Аудит ассортимента, кабинета и юнит-экономики — решение по каждому SKU, а не общие рекомендации.

/* Классический трюк: анимируем grid-template-rows 0fr → 1fr —
   работает без JS-измерения scrollHeight и без max-height-хаков */
.acc-body {
  display:grid; grid-template-rows:0fr;
  transition:grid-template-rows .35s ease;
}
.accordion.open .acc-body { grid-template-rows:1fr; }
.acc-body-inner { overflow:hidden; }  /* обязателен для 0fr */
/* Layout animation: элемент едет к новой позиции,
   а не мгновенно "телепортируется" */
.dot { position:absolute; left:4px;
        transition:left .45s cubic-bezier(.65,0,.35,1); }
.track.right .dot { left:calc(100% - 48px); }

// Для сложных случаев (разный родитель, размер) — техника FLIP:
// 1) First: запомнить getBoundingClientRect() до изменения
// 2) Last: применить изменение, снять новый rect
// 3) Invert: transform'ом визуально вернуть на старое место
// 4) Play: убрать transform с transition — элемент "едет" сам

Скролл

Прокрутите рамку внутри

Два разных приёма внутри одного скролл-контейнера: Scroll reveal — карточки проявляются через IntersectionObserver, когда попадают в зону видимости. Parallax — фон едет медленнее контента (та же техника, что двигает панели геро на главной странице сайта).

// Reveal: наблюдатель area = сам скролл-контейнер (root),
// а не viewport — иначе сработает мгновенно
const io = new IntersectionObserver((entries) => {
  entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('in'); });
}, { root: scrollBox, threshold: 0.3 });
items.forEach(el => io.observe(el));

// Parallax: фон едет медленнее (0.4×) скорости скролла контента
scrollBox.addEventListener('scroll', () => {
  bg.style.transform = `translateY(${scrollBox.scrollTop * 0.4}px)`;
}, { passive: true });
06

Обратная связь

Нажмите / потяните

Реакция на действие пользователя, а не на появление в кадре — должна быть быстрой (100–200ms), иначе интерфейс кажется тяжёлым.

Press feedback — зажмите кнопку 
.btn         { transition: transform .12s ease; }
.btn:active  { transform: scale(.93); }  /* только это, никакого JS */
Ripple — кликните по кнопке 
btn.addEventListener('click', (e) => {
  const r = btn.getBoundingClientRect();
  const size = Math.max(r.width, r.height) * 2;
  const dot = document.createElement('span');
  dot.className = 'ripple-dot';
  dot.style.width = dot.style.height = size + 'px';
  dot.style.left = (e.clientX - r.left - size / 2) + 'px';
  dot.style.top  = (e.clientY - r.top  - size / 2) + 'px';
  btn.appendChild(dot);
  dot.addEventListener('animationend', () => dot.remove());
});

.ripple-dot {
  position:absolute; border-radius:50%;
  background:rgba(255,255,255,.5); transform:scale(0);
  animation:ripple .6s ease-out forwards; pointer-events:none;
}
@keyframes ripple { to { transform:scale(1); opacity:0; } }
Shake — сигнал ошибки, кликните 
@keyframes shake {
  10%, 90% { transform: translateX(-2px); }
  20%, 80% { transform: translateX(4px);  }
  30%, 50%, 70% { transform: translateX(-8px); }
  40%, 60% { transform: translateX(8px);  }
}
.shake { animation: shake .4s ease; }

el.addEventListener('animationend', () => el.classList.remove('shake'));
Rubber-banding — потяните и отпустите 
let startX, dx = 0;
dot.addEventListener('pointerdown', (e) => {
  startX = e.clientX; dot.classList.add('dragging');
});
window.addEventListener('pointermove', (e) => {
  if (!dot.classList.contains('dragging')) return;
  dx = (e.clientX - startX) * 0.4;         // 0.4 = сопротивление
  dot.style.transform = `translateX(${dx}px)`;
});
window.addEventListener('pointerup', () => {
  dot.classList.remove('dragging');
  dot.style.transform = '';                // transition вернёт на 0 пружиной
});

.dot           { transition: transform .5s cubic-bezier(.34,1.56,.64,1); }
.dot.dragging { transition: none; cursor: grabbing; }
07

Easing

Одна дистанция, разная кривая

Все шарики проходят одинаковое расстояние за одинаковое время (1.1s) — разница только в кривой. Linear прибегает последним и выглядит механически; ease-out — то, что должно быть по умолчанию почти везде в UI.

cubic-bezier(.42, 0, 1, 1)      /* ease-in     — старт медленный, потом резко */
cubic-bezier(0, 0, .58, 1)      /* ease-out    — default для UI */
cubic-bezier(.42, 0, .58, 1)    /* ease-in-out — для объектов уже в движении */
cubic-bezier(.34, 1.56, .64, 1) /* back        — перелёт и возврат, "живая" реакция */
