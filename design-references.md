# Референсы для редизайна 27.12 Consulting

## 10 референсов по дизайну

1. [Awwwards — Bento Grid лендинги](https://www.awwwards.com/inspiration/homepage-design-bento-box-design-zoma-1) — сетка из разноразмерных плиток вместо одинаковых блоков подряд; каждая цифра/отзыв/услуга — своя карточка. Прямое решение проблемы монотонного текста.
2. [Awwwards — Interactive Bento Grid, Paradigm Solutions](https://www.awwwards.com/inspiration/interactive-bento-grid-paradigm-solutions) — тот же приём, но именно на сервисно-консалтинговой тематике.
3. [vc.ru — кейс сайта студии IGNI](https://vc.ru/design/161674-keis-korporativnyi-sait-veb-studii-igni-myagkii-skroll-brutalizm-i-3d) — разбор на русском: мягкий скролл + брутализм + 3D, с объяснением "как сделано".
4. [Skillbox — почему брутализм снова популярен](https://skillbox.ru/media/design/pochemu-brutalizm-snova-populyaren-v-veb-dizayne-i-kak-ego-ispolzovat/) — крупная жирная типографика, честные формы без градиентов и теней — стиль, который убирает "воду" из текста за счёт визуального веса заголовков.
5. [Behance — подборка "брутализм"](https://www.behance.net/search/projects/брутализм) — живая лента реальных кейсов, можно фильтровать по индустрии.
6. [Made on Tilda — галерея](https://tilda.cc/ru/madeontilda/) — примеры российских сайтов, полезно смотреть, как решают кириллицу и текстовые лендинги.
7. [Genius.Space — тренды веб-дизайна 2026](https://genius.space/ru/lab/trendy-veb-dizajna-2026-kakie-sajty-budut-prodavat-a-kakie-uzhe-ustareli/) — по-русски: необрутализм, жирная типографика, интерактивный курсор, смелые цвета.
8. [1PS — 10 трендов дизайна сайтов 2026](https://1ps.ru/blog/sites/2025/10-trendov-dizajna-sajtov-v-2026-godu/) — органические формы, микровзаимодействия, сторителлинг через визуал — с примерами.
9. [Land-book — галерея лендингов](https://land-book.com/design/landing-page) — тысячи реальных лендингов с фильтром по стилю/индустрии.
10. [Lapa Ninja](https://www.lapa.ninja/) — 7300+ лендингов, быстрый способ насмотреться на конкурентов из B2B/консалтинга.

## 10 референсов по анимациям и интерактивным фишкам

1. [Awwwards — Hovers, Cursors and Cute Interactions](https://www.awwwards.com/awwwards/collections/hovers-cursors-and-cute-interactions/) — коллекция из 466 живых ховер-эффектов и курсоров.
2. [Awwwards — Magnetic mouse cursor](https://www.awwwards.com/inspiration/magnetic-mouse-cursor-code-barcelona-for-agencies) — кнопка/курсор "притягивается" к мышке — тактильная деталь на CTA.
3. [Awwwards — Reactive cursor](https://www.awwwards.com/inspiration/reactive-cursor-1) — курсор меняет форму/подпись при наведении на разные зоны сайта.
4. [Awwwards — Animated Custom Cursor Effects](https://www.awwwards.com/inspiration/animated-custom-cursor-effects) — подборка разных кастомных курсоров для вдохновения.
5. [FreeFrontend — 60+ GSAP ScrollTrigger examples](https://freefrontend.com/scroll-trigger-js/) — большая живая коллекция готовых scroll-эффектов с кодом: построчное появление текста, параллакс, пин-секции.
6. [GSAP — официальные демо ScrollTrigger](https://gsapdemos.com/plugins/scroll/scrolltrigger) — включая горизонтальный скролл через "пин" секции (карточки услуг лентой вбок).
7. [Annnimate — 10 паттернов GSAP ScrollTrigger](https://www.annnimate.com/blog/gsap-scrolltrigger-tutorial) — готовые паттерны: fade reveal, текстовые эффекты, mask reveal, flip-анимации.
8. [Habr — управляемый прокруткой CSS в 2026](https://habr.com/ru/articles/1034960/) — нативные scroll-анимации без JS (view-timeline), по-русски, с кодом — часть эффектов можно сделать быстро без библиотек.
9. [Ю-эксперт — кастомные курсоры как тренд UX](https://m.uexpert.ru/15-kastomnye-kursory-kak-trend-ux-dizajna-v-2025-godu/) — по-русски про то, зачем и как использовать курсор как инструмент навигации/UX.
10. [Tilda Education — фиксация текста при скролле](https://tilda.education/courses/webanimation/textfix/) — русскоязычный урок про sticky-текст и анимацию заголовков при прокрутке.
